# Demo script

Tell one story. Do not tour the navigation.

An NGO came back from the Yamuna with a folder of photos. None of those files are useful until they are evidence.

1. Drop a few images on Upload. Watch the stages move from uploaded to analyzing to connecting to ready. That state comes from the job, not a fake spinner.
2. Open Review. One frame is a near-duplicate of the ITO waste pile. One has no GPS. Approve only what a person can stand behind.
3. Open the graph and show media. The new asset joins the project cluster. Click the edge and read why it was drawn.
4. Click the location and open the map. The same place is a pin, not a second database.
5. Open the Nigambodh pair. Say “visual change,” not a vegetation percentage.
6. If a TypeSafe key is set, point at the decision source. Jev chose a bounded route. The app decided whether a person still had to look.
7. Generate or open the brief. The sentences name their source files.
8. Publish, then open `/feed/river-restoration` in a private window.

Close with: this is not another photo library. It is the evidence layer between field media and a claim.
